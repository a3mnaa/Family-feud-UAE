# تحدي الدار
تطبيق Node.js بلا مكتبات إضافية. شغّل `npm start` وافتح http://localhost:3000. على شبكة محلية استخدم عنوان IP لجهاز الخادم بدلاً من localhost على أجهزة الفرق. اسمح بالمنفذ 3000 وفق سياسة الشبكة. للنشر العام استخدم استضافة Node.js تدعم عملية خادم مستمرة (مثل Render أو Railway)، وأمر التشغيل npm start. لا تستخدم استضافة Vercel serverless لهذا الإصدار لأن الغرف محفوظة في ذاكرة عملية واحدة. استخدم نسخة خادم واحدة فقط. الغرف تضيع عند إعادة تشغيل الخادم. لا توجد قاعدة بيانات أو QR مدمج حالياً. المزامنة عبر polling كل 350ms؛ ترتيب الجرس حسب وصول الطلب للخادم. المضيف يقرر سرقة النقاط بعد ثلاثة أخطاء بمنح رصيد الجولة للفريق المناسب. النقاط افتراضية وليست نتائج استبيان. آخر ثلاث جولات مضاعفة. لتعديل الأسئلة حرر questions.json. احتفظ برابط المضيف سرياً. لاستخدام الصوت اضغط تفعيل المؤثرات على شاشة العرض. هذا نموذج لمسابقة صغيرة وليس خدمة إنتاجية محصنة.
